# PSX controller selection

**Auto** selects the normal controller. The host starts it in digital mode;
the game or the in-game Analog button can switch modes without restarting.
Keyboard and gamepad sources can both select Auto. Old unlocked Analog and
D-Pad settings resolve to Auto, including after source reassignment or reload.

A title that locks a controller mode keeps its declared mode. Other console
profiles retain their own choices.

The normal controller's current digital/analog mode is owned by the running
host, not by this launcher preference.
